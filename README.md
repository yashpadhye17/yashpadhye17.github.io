# Yash Padhye — Portfolio

Personal portfolio for an AI & Machine Learning Engineer pursuing an MS in Data Science & AI at the University of Houston.

[Portfolio](https://yashpadhye17.github.io/) · [LinkedIn](https://www.linkedin.com/in/yash-padhye/) · [GitHub](https://github.com/yashpadhye17)

## Run locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

## Contents

- `index.html`: profile, experience, projects, skills, publications, and contact.
- `style.css`: responsive dark theme and reduced-motion support.
- `script.js`: mobile navigation and project filters.
- `assets/Yash_Padhye_Resume.pdf`: downloadable resume.

## Deployment

Static HTML, CSS, and JavaScript; no build step or dependencies. Configure GitHub Pages to serve the root of the publishing branch. `.nojekyll` disables Jekyll processing. Push changes to that branch to publish.

Update experience and project details in `index.html` and replace the resume PDF when needed.
